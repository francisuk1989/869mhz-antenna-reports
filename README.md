## About This Project

Antenna manufacturers often advertise optimistic gain figures (dBi) that may not accurately reflect real-world performance. Unless independently verified, advertised gain figures should be treated as manufacturer claims rather than confirmed measurements.

This repository provides antenna test reports, comparisons, and recommendations to help MeshCore and Meshtastic users choose suitable antennas.
